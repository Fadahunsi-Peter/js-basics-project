# From Static to Interactive: JavaScript DOM Basics 

Welcome to my foundational JavaScript project! This repository contains the code from my live Microsoft Learn Student Ambassador (MLSA) skilling session, where we explored how to take a static HTML webpage and bring it to life using Vanilla JavaScript.

## Project Overview
When learning web development, it is crucial to understand how the core technologies interact before jumping into heavy frameworks like React. This project serves as a practical demonstration of the Web Ecosystem:
* **HTML:** The structure and skeleton.
* **CSS:** The styling and interior design.
* **JavaScript:** The logic, electricity, and behavior.

This project demonstrates how JavaScript bridges the gap between structure and behavior using the **Document Object Model (DOM)**.

## Features
1. **Interactive Event Listeners:** A button that listens for a user `click` event to trigger a system alert.
2. **Dynamic DOM Manipulation (Theme Toggle):** A theme-switcher button that directly accesses the document's `<body>` tag to override CSS properties. It uses conditional logic to seamlessly toggle between light and dark modes without reloading the page.

## Technologies Used
* **HTML5:** Semantic structure and element IDs.
* **CSS3:** Base styling and smooth transitions.
* **Vanilla JavaScript (ES6+):** DOM manipulation, `querySelector`, and arrow functions.

## Core Concepts Mastered
Through building this project, I solidified the following JavaScript fundamentals:
* Declaring variables using `const` and `let`.
* Traversing the DOM using `document.querySelector()`.
* Attaching event-driven behavior using `.addEventListener()`.
* **State management and conditional logic** (`if/else` statements) to track and toggle UI themes.
* Dynamically modifying inline CSS styles using `element.style`.

## How to Run Locally
Because this project relies purely on Vanilla JavaScript, HTML, and CSS, no complex environment setup or package managers are required!
1. Clone this repository or download the `.zip` file.
2. Open the project folder in your code editor (e.g., VS Code).
3. Right-click on `index.html` and select **Open with Live Server**, OR simply double-click the `index.html` file to open it directly in your web browser.
